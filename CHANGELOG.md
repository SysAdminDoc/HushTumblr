# Changelog

## Unreleased

* **Tumblr:** Quick setups can be hidden from the settings home with a long press on its row, and its help line now says so. The **Quick setups on the home page** row on Pause, backup and diagnostics brings it back. The choice stays out of settings backups and Quick setups, and Pause leaves it alone.
* **Tumblr:** Hide note counts now takes the numbers off the Comments, Reblogs and Likes tabs on a post's notes too. The tabs still switch, and the numbers come back once the switch is off and the notes are opened again.
* **Tumblr:** The Words to hide and Allowed words editors now shrink to fit above the keyboard. With large text and the Samsung keyboard open, Save and Cancel used to sit behind the keyboard.
* **Tooling:** Every Tumblr method a patch run changes or adds now has to be one a mutation contract checked, or be listed in `scripts/dex-delta-allowlist.txt` with the digest of what the patch writes there, under a patch the run selected. The same goes for each field or interface a patch adds to a Tumblr class, and for any extension method a patch fills in beyond the flags and version string the patcher writes. A class added under the extension's package has to be one the bundle carries. A run that names its patches also fails on an allowlist line for code it left alone or for a digest that's out of date, and a run over an installed build checks against every section. Code two patches write together goes under a section that joins them with " + ", which only applies when the run selects both and then stands in for a line either one has on its own. A Tumblr class carried in more than one dex entry has to be the same in every copy, methods included. A Tumblr method or extension class edited in the patcher's working copy used to pass as long as its code was well formed. The bundle is also held open for the whole run now, so it can't be swapped between the patch and the check.
* **Tooling:** When most of the bundle's extension classes differ from the ones in the APK being checked, `verify-injected-registers.ps1` now adds a line saying the APK may have been patched from another build of the bundle, and names `-Bundle` to hand that one over.
* **Tooling:** `patch-for-device.ps1` now checks that the APK it hands on is signed by the keystore alias's key and no other, read from the keystore with keytool, before it copies or installs anything. The keystore is held from that read, before anything signs, to the end of the run, by its full path even when it's given as a relative one. A build signed by some other key, or not signed at all, used to get through, because the checks before it skip the signature files.
* **Tooling:** Patch runs now hold the merged APK from the moment the merger writes it, so another program on the PC can't swap it before the patcher and the checks read it. The package and version a run was let through on are read again off that held file before anything is patched.
* **Tooling:** `patch-for-device.ps1 -Option 'Patch name:key=value'` gives a patch an option value for a test build, such as a custom Dark background color. A run with an option always patches in full instead of reusing a kept run.
* **Tooling:** A kept patch run is now looked up by what the held merge was made from, not by the fixture's path, and the kept patched APK and its result report are held to the digests they were kept with while they're reused. A fixture changed between runs no longer finds the run kept for its old bytes, and neither does a bundle whose APKs were renamed or swapped. A kept APK or report that changed after it was kept isn't reused. Reusing a kept run in `verify-all-patches.ps1` now costs a merge.
* **Tooling:** The patch report check no longer stops with an error on a report that lists no patching steps. It fails that report with the missing-step reason instead. A report that leaves out its failed patch list isn't counted as having one failure any more, and `verify-all-patches.ps1` and `patch-for-device.ps1` no longer print one for it.
* **Tooling:** The release receipt now names each fixture by the digest taken as it was read for the merge, not by hashing the file again once the run is over. Each APK unpacked or copied for a merge is also held to the bytes written for it, so one changed before it's checked is refused.
* **Tooling:** The release receipt and the release gate now patch and check every fixture themselves instead of reading kept runs. A kept run is a report and an APK that any program on the PC could write together, so it can't show which bundle made the APK. The gate still keeps each run that passes for `patch-for-device.ps1`. Building a release takes longer as a result. Local runs still reuse kept runs.
* **Tooling:** The patched APK and result report are now held from the moment the patcher exits, so nothing can swap them before the checks read them, and a kept run is copied from those held files. The patcher works on a copy of the merge that nothing holds, so the resource check now also compares the archive entries patching doesn't rewrite against the merge's own bytes. Those are all of them but the dex, the resource table, the manifest, the signature files and the files the patched table names that the stock one doesn't. `patch-for-device.ps1` runs that check on every build it patches.
* **Tooling:** For an unsigned universal APK, the release receipt and the record beside its merge now name the bundle it was trusted on, by that bundle's digest as it was read to be checked. The receipt used to leave it out, and the record named it only by its path, which says nothing about the bytes that were checked. The release check refuses a receipt that names one for a bundle, since a bundle is trusted on its own signatures.
* **Tooling:** Every change a patch run makes to Tumblr's resource table, and every file it adds or moves, now has to be listed in `scripts/resource-delta-allowlist.txt`, either as something any rebuild of the table does or under a patch the run selected. Each line allows one change. An added resource is listed with every value it holds (a style with its parent and each item), with the color the Dark background color option picks left open as long as every one of those values comes from the same solid color, and an added file with the digest of its bytes. Two values that differ never read alike in the report, whether it's a backslash in a string, bold text next to the same tags typed out, a color written in another form or a dynamic reference, and a style that sets one attribute twice gets a line for each. A table or file swapped into the patcher's working copy used to pass as long as every stock resource still resolved. A moved resource file is now compared by its bytes instead of its CRC and size, and only ASCII names count as signature files.
* **Tooling:** An APK or report the patcher didn't leave behind now counts as missing, even if a file shows up at that path later. A device build signed from a kept run is compared entry by entry with the kept APK, and a kept run is only saved from files held so nothing else can write to them.
* **Tooling:** A bundle APK whose name passes the name check only when case is ignored (the Kelvin sign reads as a k) is now refused before anything is unpacked, instead of stopping the run after the merge.
* **Tooling:** The script tests now clean up after themselves. The pre-push cases remove the worktree the hook builds in, and a passing host reference run deletes its report folder. Each run used to leave both in the temp directory.

## 0.0.7 (2026-10-14)

* **Tumblr:** With Debug logging on, the log now says how long the settings' restart marker took to save and to read back, and how long Clear diagnostic data and its undo kept the log locked.
* **Tumblr:** With Tumblr set to a right-to-left language, the settings' page titles, section headings, search field and dialog labels now sit on the same side as the rows. They used to stay at the left.
* **Tumblr:** The Support HushTumblr row at the bottom of the settings is now just its title. The line under it is gone, and a tap still opens the Ko-fi page.
* **Tumblr:** The Hide Blaze prompts switch now says that the Blaze item in a post's menu stays. It hides the buttons, banners and after-post nudge, as before.
* **Tumblr:** The HushTumblr settings shortcut on Tumblr's icon now opens the settings every time. If Tumblr was still open from the last time you used the shortcut, tapping it again only brought Tumblr back up.
* **Tumblr:** Hide suggested communities no longer empties a category in Communities' Browse page. The communities listed there stay, and the suggestion cards still go from your dashboard and other feeds.
* **Tumblr:** A page where every post was hidden no longer leaves a feed on "No results". The feed goes on to the next page, and shows the empty screen only after five empty pages in a row or when there's nothing more to load.
* **Tumblr:** Hide suggested blogs and Hide suggested communities no longer empty a search's Blogs and Communities tabs. The cards still go from the dashboard and other feeds.
* **Tumblr:** Visible image descriptions now use the same text color as the post, so they're readable in Tumblr's default True Blue palette. They used to come out light gray on the white card.
* **Tumblr:** The Tumblr's own settings page now lists where Tumblr keeps six of its own controls, such as autoplay, the dashboard order and filtered tags. Each row shows the path to the control in the language Tumblr is using.
* **Tumblr:** Dark background color now reaches Tumblr's newer settings screens and the redesigned post card, which used to stay gray. Bars, rows and dialogs sit one step lighter than the page.
* **Tumblr:** Hide the Communities tab now takes the Communities button off the bottom bar on every start. It used to come back after a restart with nothing behind it.
* **Tumblr:** Manage muted posts now tells you when this account's list couldn't be read and gives you a Retry button, including when the app was too busy at sign-in to read it. Nothing is changed or deleted while it can't be read.
* **Tumblr:** Manage muted posts now says that this device keeps muted post lists for eight accounts, and that a ninth account's first mute deletes the list that's gone longest without a change.
* **Tumblr:** Hide reblogs has a new option, Keep reblogs with added content. Turn it on to keep reblogs where the reblogger added something of their own while empty reblogs stay hidden.
* **Tumblr:** The setup guide's two help buttons now open Tumblr's own articles on resetting a password and on requesting your personal data. The guide also says that request is made on Tumblr's website, not in the app.
* **Tumblr:** Long-press the Tumblr logo at the top of your dashboard to open HushTumblr settings. A tap on the logo still does what it always did.
* **Tumblr:** Quick setups, under the status card, turns on the Quiet or Privacy switches in one tap, or puts every switch back. A toast says how many changed.
* **Tumblr:** Report a problem sits just above the Ko-fi row. It opens a GitHub bug report with your versions, phone and switches filled in.
* **Tumblr:** Settings search no longer matches the word "null" on rows that have no description.
* **Tumblr:** A change that needs a restart puts a Restart row at the top of every settings page. Tap it and Tumblr reopens on the same page. Hide ads now asks for it too.
* **Tumblr:** Every settings page opens straight from the HushTumblr home page. Links, Notifications, Updates, backup and About moved off their own More settings page and now sit under a More settings heading, so nothing is more than one tap deep. With TalkBack on, Back scrolls to the row you came from when it's off screen, so focus lands there right away.
* **Tumblr:** Settings pages have larger headers and short descriptions. Each control has its own navy card, with clearer spacing and rectangular switch thumbs. Short windows use a compact header to keep the list within reach.
* **Tumblr:** The status card puts Pause or Resume below its message. Both actions save on a worker and prevent repeated taps. Choice dialogs share the page styling, and tab-order rows show an upward arrow for their move action.
* **Tumblr:** Tab-order actions now draw upward arrows. Switch tracks keep their full size, with evenly inset thumbs.
* **Tumblr:** A local mute that can't refresh the feed or undo itself keeps an Unmute post action. Recovery changes only that post and preserves later edits to the account's muted list.
* **Tumblr:** Clearing diagnostic data and putting it back use a shared worker operation. Rows show progress, prevent repeated actions and keep failed restores available to retry.
* **Tumblr:** Word lists, tab order and switches save on a worker. Busy controls keep the saved value visible, block repeated taps and report failures. Replacement settings pages refresh when an edit finishes. Backup actions stay busy while a failed refresh waits to retry.
* **Tumblr:** Backup previews and import results count word lists and tab order alongside switches. Import and Undo messages now refer to settings, and the setup guide explains which data the backup includes.
* **Tumblr:** Settings controls now show focus and disabled states consistently. Search and word fields have clearer boundaries, and dialog actions wrap without losing their touch targets at large text sizes.
* **Tumblr:** Word editors keep a label above the list, explain when changes are saved and show save errors beside the draft. Long explanations and errors scroll with the editor while Save and Cancel stay within reach.
* **Tumblr:** The muted-post manager keeps Undo in its own window. Failed changes leave the list available to retry, empty lists explain how to mute a post, and switching accounts closes the old list. Undo also respects Android's accessibility timeout.
* **Tumblr:** A release check that can't save its result now reports the failure instead of showing an earlier success. Closing settings also closes the setup guide and disables its old actions.
* **Tumblr:** HushTumblr settings and their dialogs now mirror navigation for right-to-left languages, even when Tumblr's own layouts don't support it.
* **Tumblr:** Moving a tab keeps TalkBack focus on that tab and announces its new position. Reset and refused saves keep focus aligned with the saved order.
* **Tumblr:** Hide ads also removes paid Blaze posts from blogs you don't follow. It keeps your own posts and posts from blogs you follow.
* **Tumblr:** Long word lists now scroll inside the editor, keeping Save and Cancel within reach.
* **Tumblr:** Saving a word list during an import now checks and saves the combined size in one step. Older backups ignore unsupported allowed-word fields instead of rejecting the whole file.
* **Tumblr:** Failed saves keep the words draft and the earlier tab order. The words editor also keeps its draft and selection when the settings page is recreated. Import and Undo refresh the list summaries and retain any required restart notice.
* **Tumblr:** Settings backups check the complete file size before replacing an export. Oversized saved lists stay available to edit, and a refused Save keeps the draft. Diagnostic choices close with their settings page.
* **Tumblr:** Word matching recognizes canonically equivalent text and checks whole words by Unicode code point. Added field choices and allowed words. Those exceptions affect the word filter only. Hide reblogs can optionally keep reblogs with their own tags.
* **Tumblr:** Added activity filters for likes, reblogs, replies, follows, mentions, asks and boops. They start off and leave push notification choices alone. Post timestamps and visible image descriptions also start off.
* **Tumblr:** Added private post muting to the native post menus, including the redesigned menu and your own blog's menu. It removes originals and their reblogs, with Undo and account-specific management. Optional mature-content reveal keeps Tumblr's age and account restrictions.
* **Tumblr:** Optional mutual markers use a follower cache for your primary blog. Unknown relationships and sideblogs keep their existing headers.
* **Tumblr:** Refreshed every HushTumblr settings page with navy cards, pale blue controls and larger page titles. Navigation has outlined icon tiles, and switch descriptions have more room.
* **Tumblr:** Backup and diagnostic actions now have separate cards. The words editor, tab order list and other dialogs use the same colors as the settings pages. Search, recovery and enlarged text follow the new design too.
* **Tumblr:** Kept the existing settings, defaults and saved choices. Added current settings screenshots to the README.
* **Tooling:** Patched APKs are now checked for devices with 16 KB memory pages before they're kept, receipted or signed for a phone, and Tumblr's own native libraries are confirmed untouched.
* **Tooling:** An unsigned universal APK now has to match the merge of the signed bundle beside it file for file, so one that leaves an asset out or carries a swapped resource or resource table is refused before patching.
* **Tooling:** The settings, pause and restart checks now also run against Android 17 (API 37).
* **Tooling:** The patch scripts refuse a bundle whose file names try to reach outside the folder it's unpacked into. They also check every APK in it against Tumblr's signing certificate, package and version before anything is merged, patched, signed or installed. A bundle that would unpack past 1 GB for one APK, or 2 GB in all, is refused before anything is written, and so is an .xapk whose manifest.json would pass 1 MB. A merged universal APK kept beside its bundle now has to carry that bundle's own files throughout, not only its code and native libraries.
* **Tooling:** Settings title checks compile against the public Android SDK.
* **Tooling:** Split-input tests check AAPT2's complete manifest split name. Gate-isolation fixtures include both suites that shared merge changes require.
* **Tooling:** Concurrent device-build tests keep their queue log intact on Windows PowerShell 5.1.
* **Tooling:** Expanded compiled-code checks to cover every patch family and its original fallback, including the redesigned post menus and their retained timeline owners. Altered hooks are rejected before a device build.
* **Tooling:** Gallery cleanup is checked against the captions it owns, including recycling while the feature is paused. The verifier rejects unowned removals and escaped caption references.
* **Tooling:** Updated the checked Gradle wrapper to 9.8.1. Build and release entry points reject an affected, incomplete or mismatched wrapper before it runs.
* **Tooling:** Source updates can keep their notes under Unreleased while the published bundle stays on its released version. Release checks still require a dated entry.
* **Tooling:** The README is much shorter now and sticks to what you need to install and use HushTumblr. The longer version is still in the repository history.

## 0.0.1 (2026-10-12)

* **Tumblr:** First release. HushTumblr 0.0.1 starts from HushPinterest and supports Tumblr 46.5.0.109 (version code 1460500109) on Android 8.0 or newer, with 36 patches.
* **Tumblr:** Six patches carry over and now point at Tumblr: HushTumblr settings, Disable analytics, Hide advertising ID, Remove ad tracking permissions, Fix push notifications and Spoof signature for Google sign-in.
* **Tumblr:** HushTumblr settings has a row of its own at the end of Tumblr's Settings screen, and still opens from a long-press on the Tumblr icon and from Tumblr's App info page. The row's title is the one string HushTumblr adds to Tumblr's resources.
* **Tumblr:** Patch descriptions now point at Tumblr settings > HushTumblr for each switch.
* **Tumblr:** The patches now declare all four ABIs Tumblr's 46.5.0.109 bundle carries (arm64-v8a, armeabi-v7a, x86 and x86_64), so Morphe Manager offers them on 32-bit phones and x86 emulators too, not just 64-bit ARM.
* **Tumblr:** A shared hook on Tumblr's feature check lets a HushTumblr switch turn one of Tumblr's own features off. It has no switch of its own, and what it changes shows after Tumblr restarts, since Tumblr keeps each answer until then.
* **Tumblr:** New Hide ads patch, on by default. It takes ad cards and posts Tumblr serves as sponsored out of your dashboard, blog pages, likes and search before Tumblr shows them, and turns off Tumblr's switches for asking its ad networks for ads once Tumblr restarts. The switch is on the new Feed page in HushTumblr settings.
* **Tumblr:** Disable analytics now has a switch, on by default, on the Privacy page. It turns off Tumblr's own tracking once Tumblr restarts: LiveRamp's ID on its requests, Open Measurement and Moat ad measurement, and its logs of which features you saw, network use, app performance and ad supply. The Firebase and Google part still stays until you patch again without it.
* **Tumblr:** New Hide the ad-free banner patch. Its switch, off to start and on the Feed page, hides the dashboard banner that asks you to pay for Ad-Free Browsing once Tumblr restarts.
* **Tumblr:** New Hide Tumblr TV patch. Its switch, off to start and on the new Interface page, takes the Tumblr TV tab out of the bottom bar and stops sign-up from sending you there, once Tumblr restarts.
* **Tumblr:** New Hide the Communities tab patch. Its switch, off to start and on the Interface page, takes the Communities tab out of the bottom bar and stops the Communities tips in the post editor, once Tumblr restarts.
* **Tumblr:** New Hide Blaze prompts patch. Its switch, off to start and on the Interface page, hides the buttons, banners and after-post nudge selling Blaze, Tumblr's paid post promotion, once Tumblr restarts.
* **Tumblr:** New Skip review prompts patch. Its switch, off to start and on the Interface page, stops the "What do you think of the Tumblr app?" pop-up that leads to a store rating or a feedback form. It's read each time the pop-up would open, so it works without a restart.
* **Tumblr:** New Turn off screenshot sharing patch. Its switch, off to start and on the Interface page, stops Tumblr watching for screenshots and opening its offer to save the post as an image, once Tumblr restarts.
* **Tumblr:** New Disable update prompts patch. Its switch, off to start and first on the Updates page under More settings, stops Tumblr asking Google Play for a newer Tumblr and showing Play's update prompt, once Tumblr restarts.
* **Tumblr:** New Hide suggested blogs, Hide suggested communities and Hide Watch it rows patches. Their switches, off to start and on the Feed page, take the "Check out these blogs" and "Check out these communities" cards and Tumblr TV's Watch it rows out of your dashboard and other feeds as each page loads. A carousel goes when its first card is one of them, and the heading in front of a card goes with it.
* **Tumblr:** New Hide hashtags and Hide the Follow button patches, with their switches off to start on a new Posts page in HushTumblr settings. Hide hashtags takes the tags off the bottom of posts and keeps the source link and badges in that row, and clears the tags Tumblr TV writes under a video that has no description. Hide the Follow button takes the button out of the header of posts from blogs you don't follow yet. Both apply to the next post that scrolls in, without a restart.
* **Tumblr:** New Hide note counts, Hide the like button, Hide the reblog button, Hide the comment button and Hide the share button patches, with their switches off to start on the Posts page. Hide note counts takes the like, reblog and comment counts off the footer under posts and keeps the buttons working, and shows on the next post that scrolls in. Where Tumblr writes the count as words, on a community post's comment button and at the top of a post's notes, you get Tumblr's own "Comments" or "Notes" instead. Each button switch takes that one button out of the footer once Tumblr restarts. Community posts have their own footer, and the comment and share switches reach it too. They have no like button, so Hide the like button takes their reactions off instead.
* **Tumblr:** New Hide the diamond and TumblrMart patch. Its switch, off to start and on the Interface page, hides the Premium diamond and the TumblrMart button at the top of your dashboard, Explore and notifications once Tumblr restarts. Explore's search bar then runs on into the space the two icons left. Premium itself isn't touched, so checkout and perks keep working for members.
* **Tumblr:** New Hide unread dots patch. It puts three switches on the Interface page, all off to start: Hide the Dashboard count, Hide the Communities count and Hide the Notifications count. Each one hides the unread dot or count on its own tab of the bottom bar the next time Tumblr updates its counts, so you can keep the one you care about.
* **Tumblr:** New Hide reblogs patch. Its switch, off to start and on the Feed page, takes reblogs out of your dashboard and other feeds as each page loads and keeps the posts people made themselves.
* **Tumblr:** New Hide video posts patch. Its switch, off to start and on the Feed page, takes posts with a video anywhere in them out of your feeds as each page loads. The reblogged part counts, so a comment reblogged onto a video is a video post too.
* **Tumblr:** New Hide photo posts patch. Its switch, off to start and on the Feed page, takes posts with pictures and no video out of your feeds as each page loads, the reblogged part included.
* **Tumblr:** New Hide text posts patch. Its switch, off to start and on the Feed page, takes posts with no pictures or video out of your feeds as each page loads, the reblogged part included.
* **Tumblr:** New Hide posts with these words patch. Its switch, off to start and on the Feed page, takes a post out of your feeds when its text, reblog trail, tags or summary has a word or phrase from the list you type in under it. Case doesn't matter and only whole words count.
* **Tumblr:** New Dark background color patch. Its switch, off to start and on the Interface page, makes the background of Tumblr's Dark Mode palette black once Tumblr restarts, which can save battery on OLED screens. The patch's Background color option picks another dark color instead. Cards get the same color and highlighted parts a shade lighter, and the other palettes, light ones included, stay as they are. The System palette gets it at night, when it uses Dark Mode.
* **Tumblr:** New Hide the Explore tab patch. Its switch, off to start and on the Interface page, takes the Explore and search button off the bottom bar once Tumblr restarts. The tab itself stays, so a link into Explore still opens it.
* **Tumblr:** New Hide the Notifications tab patch. Its switch, off to start and on the Interface page, takes the Notifications button off the bottom bar once Tumblr restarts. A link into your notifications still opens them.
* **Tumblr:** New Reorder the bottom bar patch. Its switch, off to start and on the Interface page, puts the bottom bar's tabs in the order you set in the Tab order list under it, once Tumblr restarts. A tap on a tab in that list moves it up a place, and Tumblr's order puts them back. Tumblr still opens on Dashboard, and each button and each link into a tab still opens its own tab. Tumblr TV and Communities are skipped while their own switches keep them off the bar, and Dashboard and Account always stay.
* **Tumblr:** New Hide the Save button patch. Its switch, off to start and on the Posts page, takes the Save button out of the footer under posts once Tumblr restarts. Tumblr only draws that button when its own Save feature is on for you, so without it there's nothing to hide.
* **Tumblr:** Hide note counts now takes the number off each reaction on community posts too, and leaves the emoji.
* **Tumblr:** Export settings now saves your words to hide and your tab order along with the switches, and Import settings brings them back. A settings file from before this still imports its switches and leaves both as they are. If a file's word list or tab order can't be used, the import preview says so and leaves it out, and the rest of the file still imports.
* **Tumblr:** The switches that answer Tumblr's own feature flags (Disable analytics, Hide the ad-free banner, Hide Tumblr TV, Hide the Communities tab, Hide Blaze prompts, Turn off screenshot sharing and Disable update prompts) now act like the other switches that need a restart. Changing one puts "A change here applies after Tumblr restarts." at the top of its page and shows the restart toast, so their own descriptions no longer end in "Restart Tumblr to see the change."
* **Tumblr:** The diagnostics report now counts any Tumblr feature check a HushTumblr switch claims that runs before HushTumblr has started, since Tumblr keeps that first answer until it restarts. Reading Tumblr 46.5.0.109 found none.
* **Tumblr:** Fix push notifications hands Firebase Tumblr's original certificate fingerprint in its request builder, and Hide advertising ID answers Tumblr's ad ID lookups with an empty ID.
* **Tooling:** The Pinterest-only patches, their settings and their checks are gone. The build, the settings framework, diagnostics, pause and backup stay.
* **Tooling:** Every package, setting key, environment variable and script now uses the HushTumblr and Tumblr names, the fixtures and stand-in builds are Tumblr's, and the patched minimum Android version is API 26.
* **Tooling:** NOTICE, provenance.json and every source header name HushPinterest at debdac4 as the upstream, with the earlier Hush projects behind it.
* **Tooling:** Added the navy H icon, README poster and social preview, kept the artwork masters and design brief, and cleared stray near-transparent pixels around the icon.
* **Tooling:** patches-list.json was written by hand for this first version and gets regenerated by the first Gradle run.
